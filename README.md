# 📊 Análise de Dados de Recursos Humanos com PySpark

## 📌 Objetivo

Este projeto demonstra o uso do PySpark para tratamento, transformação e análise de dados de Recursos Humanos.

O objetivo foi aplicar conceitos de processamento distribuído utilizando DataFrames do Spark para manipulação de dados e geração de informações relevantes para análise.
